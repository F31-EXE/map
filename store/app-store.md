**Описание (Description):**
```
GrimMap — тактическая карта для страйкбола и милсима. Весь отряд на одной карте: кто где, где противник, куда идти.

ОТРЯД НА КАРТЕ
• Позиции бойцов в реальном времени, направление взгляда и роль: пулемётчик, снайпер, медик, разведчик и другие
• Статусы «жив», «убит», «АФК» — командир видит, кто в игре
• Вступление в отряд по коду или QR-коду, без регистрации

МЕТКИ И ПРИКАЗЫ
• Противник, цель, опасность, точка сбора, медик, заметки
• Приказы «Двигаться сюда», «Атаковать», «Оборонять» — со звуком и вибрацией у бойцов
• Стрелки манёвра прямо на карте
• Метки полигона: респ, мертвяк, парковка, администрация
• Устаревшие метки скрываются голосованием отряда

РЕЖИМЫ ИГРЫ
• Зона контроля с хотзоной: горячий круг переезжает внутри зоны по таймеру, новая точка видна заранее
• Таймер вертолётного респа: «следующая группа через 2:28», вибрация убитым перед вылетом

БЕЗ ИНТЕРНЕТА
• Скачайте карту района перед игрой — спутник откроется и без связи
• Маршруты записываются на телефоне и отправляются, когда появится сеть

КОМАНДОВАНИЕ
• Сторона: несколько отрядов под одним командиром, приказы командирам отрядов
• Чат отряда с закреплённым сообщением
• Запись игры: маршруты и тепловая карта для разбора после боя

ПОДЛОЖКИ
• Спутник и схема Яндекса, Esri, OpenStreetMap, OpenTopoMap
• Импорт карт полигона: KML, KMZ, GPX, GeoJSON
• Сетка координат UTM

Без рекламы и без регистрации. Работа в фоне — по желанию, с уведомлением в шторке.
```

## Проверка приложения (App Review Information)

**Вход в систему (Sign-in required):** снять галочку — регистрации нет.

**Заметки для проверяющего (Notes)** — вставить на английском:
```
GrimMap is a team map for airsoft games. No account is needed (anonymous sign-in).

To try the team features:
1. Settings tab: enter any callsign (e.g. "Tester").
2. Squad tab ("Отряд"): tap "Создать" (Create), enter a name, tap "Создать команду". You are now the squad commander.
3. Map tab: tap the green "+" button to place markers or orders. At the bottom of that dialog, "Зона контроля с хотзоной" starts the control-zone game mode.
4. Chat tab: squad chat.

Location: used to show the player and share it with their squad. "Always" location is requested only when the user turns on "Работа в фоне" (background mode) in Settings, so teammates keep seeing them while the phone is in a pocket during a game; a notification is shown while it is active.

Account/data deletion: Settings → "Удалить мои данные".
```

**Контакт:** ваши имя, телефон и e-mail — их видит только Apple.
