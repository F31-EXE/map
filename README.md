# GrimMap — тактическая карта для страйкбола

Мобильное приложение (Android / iOS) на Expo + React Native.

- **Спутник Яндекса** (а также Яндекс гибрид/схема, Esri, OpenTopoMap, OSM). Тайлы Яндекса отрисовываются в их родной проекции EPSG:3395, поэтому не съезжают.
- **Карты полигона**: импорт KMZ (включая растровые Garmin Custom Maps с `GroundOverlay`, в т.ч. повёрнутые), KML, GPX, GeoJSON. Файлы хранятся на телефоне и показываются поверх подложки.
- **Команды**: создаёте команду и получаете 6-значный код, товарищи вступают по нему. Позиции участников видны на карте в реальном времени (если давно не обновлялись, отметка бледнеет).
- **Роли**: командир, старшина, автоматчик, пулемётчик, снайпер, медик. Боец на карте — круг цвета команды с иконкой роли и указателем направления, так сразу видно, где кто.
- **Цвет команды** выбирает её создатель, все бойцы рисуются в нём.
- **Права командира**: создатель команды может выдать любому бойцу право отдавать приказы («Двигаться сюда», «Атаковать», «Оборонять»). Новый приказ приходит без всплывающих окон: вибрация и короткий сигнал. Звук можно выключить.
- **Метки**: противник, свои, цель, опасность, точка сбора, медик, заметка. Ставятся долгим нажатием или кнопкой в перекрестие. Переключатель «Бойцам / Только мне»: личные метки хранятся только на телефоне.
- **Аватар**: фото из галереи, сжимается до 128×128 и виден команде.
- По нажатию на метку или товарища показываются координаты, дистанция и азимут от вас.
- Компас: конус направления на вашей отметке.
- Работает в вертикальной и горизонтальной ориентации.

## Быстрый старт

```bash
npm install          # заодно собирает HTML карты (scripts/build-map-html.mjs)
cp .env.example .env # заполнить, если нужны команды (см. ниже)
npx expo start
```

Откройте проект в **Expo Go** на телефоне (QR-код в терминале). Все используемые модули входят в Expo Go, отдельная сборка не нужна.

Без `.env` приложение работает в одиночном режиме: карта, импорт карт и личные метки.

Работает и веб-версия (`npx expo start --web`): удобно открыть карту на штабном ноутбуке. Импорт карт полигона в браузере пока не поддерживается.

### Локальный сервер без облака

```bash
npx firebase-tools emulators:start --only auth,firestore --project demo-tacmap
```

и в `.env`:

```
EXPO_PUBLIC_FIREBASE_API_KEY=demo-key
EXPO_PUBLIC_FIREBASE_PROJECT_ID=demo-tacmap
EXPO_PUBLIC_FIREBASE_APP_ID=1:1:web:1
EXPO_PUBLIC_FIREBASE_EMULATOR_HOST=192.168.1.10   # IP компьютера в локальной сети
```

## Настройка сервера (Firebase) для команд

1. Создайте проект на <https://console.firebase.google.com>.
2. **Authentication → Sign-in method** → включите **Anonymous**.
3. **Firestore Database** → создайте базу (регион `eur3` или ближайший).
4. Загрузите правила доступа из `firestore.rules`: вставьте их в консоли (Firestore → Rules) или выполните `npx firebase-tools deploy --only firestore:rules`.
5. **Project settings → Your apps → Web app**: скопируйте конфиг в `.env` (переменные `EXPO_PUBLIC_FIREBASE_*`).

Бесплатного тарифа Spark хватает с запасом: позиция отправляется не чаще раза в 4 секунды и только при перемещении больше 3 м (плюс раз в 30 секунд сигнал «я на связи»).

## Сборка APK

Облачная сборка Expo (EAS), Android Studio не нужен. Настройки Firebase для сборки лежат в `eas.json` (это публичные значения, они всё равно попадают в приложение).

```bash
npx eas-cli@latest login                                   # бесплатный аккаунт expo.dev
npx eas-cli@latest build --platform android --profile preview
```

Первый запуск спросит, создать ли проект на expo.dev и сгенерировать ли ключ подписи, на оба вопроса ответить «Y». Через 10–20 минут появится ссылка и QR-код на APK.

## Структура

```
src/app/            экраны (expo-router): index — карта, team — команда, maps — карты полигона
src/map/web/        код карты внутри WebView (Leaflet), инлайнится в mapHtml.generated.ts
src/map/TacticalMap.tsx   React-компонент карты и протокол обмена с WebView
src/map/MapFrame*.tsx     хост карты: WebView на телефоне, iframe в браузере
src/ui/             дизайн-система: тема, стеклянные панели, шторки, кнопки
src/state/          сессия (позывной, команда, метки) и загруженные карты
src/services/       Firestore (команды, позиции, метки), импорт файлов
src/lib/            геометрия, типы, распаковка KMZ
firestore.rules     модель данных и права доступа
```

## Ограничения и что дальше

- Позиция передаётся, пока приложение открыто на экране. Для фоновой передачи нужен `expo-task-manager` и dev-сборка (не Expo Go).
- Тайлы подложки не кэшируются офлайн: на полигоне без интернета видны только импортированные карты. Если нужно, следующим шагом можно добавить скачивание района заранее.
- Импортированные карты есть только на телефоне, который их загрузил. Раздавать их команде можно через Firebase Storage.
- `gx:LatLonQuad` (нерегулярно искажённые оверлеи) приближается прямоугольником.
- Тайлы Яндекса подключены напрямую. Условия использования Яндекс Карт такое не разрешают для публичных приложений. Для личного и клубного использования это обычная практика, но перед публикацией в сторах нужна лицензия или другой источник снимков.
